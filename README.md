📊 100 Days of Data Science Projects

A Complete Journey from Beginner to Advanced — Machine Learning, Deep Learning, NLP, and Cloud Deployment

🧠 Overview

This repository contains 100 data science projects built over 100 days.
Each project focuses on practical implementation, hands-on learning, and end-to-end deployment — from basic EDA to cloud-based ML apps.

Final project: ☁️ Cloud Deployed Sentiment Analysis App (AWS + Flask + Pickle model)

🚀 Categories Covered
Day Range	Theme	Example Projects
1–10	Python for Data Science	NumPy, Pandas, Matplotlib, Seaborn
11–25	Exploratory Data Analysis (EDA)	Titanic, Netflix, COVID-19 Data
26–40	Machine Learning	Linear Regression, Decision Tree, Random Forest
41–55	Deep Learning	CNN for Image Classification, MNIST
56–70	Natural Language Processing (NLP)	Sentiment Analysis, Spam Detection
71–85	Time Series & Forecasting	Stock Price Prediction, Weather Forecast
86–95	MLOps Basics	Model Serialization, Pipeline Building
96–100	Cloud Deployment	AWS EC2 + Flask App using Pickle Model
⚙️ Final Project Highlight: Cloud-Deployed Sentiment App

🧠 Trained Model: Logistic Regression / Naive Bayes (Pickle saved model)

☁️ Deployment: AWS EC2 instance + Flask server

💬 Functionality: Predicts Positive or Negative sentiment

🌐 Frontend: Simple HTML UI

🧩 Storage: S3 or Local JSON logging

Example Input/Output:
